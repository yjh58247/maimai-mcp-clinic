# 常见问题

## 找不到 node，或启动窗口提示版本过低

安装 [Node.js](https://nodejs.org/en/download) 22 或更高版本，重新打开终端，运行 `node --version`。Windows 可再双击 `启动体检站.cmd`。无须执行 `npm install`。

## Cannot find module，或启动文件不存在

完整解压 ZIP，在包含 `package.json` 和 `server.mjs` 的文件夹中启动。不要在压缩包预览窗口直接运行，也不要只复制启动脚本。

## 网页打不开，或仍显示旧版本

保持启动服务的终端窗口打开，使用它输出的完整本机地址。默认端口 4319 被占用时，新服务会尝试后续 9 个端口；旧标签页可能仍连接旧服务。页面右上角可核对版本。若所有候选端口均被占用，可在本机 `.env` 中将 `PORT` 改为另一个未占用端口后重启。

## 已填写 Token，网页仍提示未配置

确认文件名为 `.env`，与 `server.mjs` 同目录，而不是 `.env.txt`。确认填写的是 `MCD_MCP_TOKEN=` 后面的值，保存后重启。环境变量优先于 `.env`；启动终端中的同名空变量也会关闭真实接入。

网页模式由本机服务读取 `.env`；独立 CLI 的 `connect` / `call` 从环境变量读取，需在运行 CLI 的终端单独配置。

## 401、403 或真实连接失败

在[麦当劳开放平台](https://open.mcd.cn/mcp)核对凭证有效性与账号权限；本机更新配置后重启。401 / 403 本身不能确定唯一原因，请同时查看诊断里的脱敏错误信息。离线案例可以继续体验。

DNS、TLS、连接重置或超时提示通常需要检查本机网络及代理设置。不要通过关闭 TLS 校验处理；保留脱敏错误信息供排查。

## 429 请求频率限制

遵循接口返回的 `Retry-After` 或等待后再试，避免反复点击。客户端不会自动重试限流请求。

## CLI 输出退出码 2

表示报告内存在需要修复的诊断项；例如 `demo price-unit` 故意演示金额错误。退出码 0 表示记录内检查通过，1 表示文件、参数、网络或执行错误。

## 导入报告标记“未进行实时验证”

这是预期行为。导入只对已有记录重新分析，不会重新发送真实请求，也不证明当下门店、菜单或价格仍相同。

## 刷新失败后门店、商品或模板默认值消失

最新一次查询失败后，体检站会停止自动复用对应的旧结果，避免把旧数据当成刷新成功。根据错误提示处理连接、参数或权限问题，再重新查询同一场景；成功后门店、菜单或详情模板会恢复。历史成功与失败记录仍可在报告中查看。

## 如何反馈

使用[问题／建议模板](https://github.com/yjh58247/maimai-mcp-clinic/issues/new/choose)，说明项目版本、系统、Node.js 版本、复现步骤、预期和实际结果。优先用离线案例或最小参数复现。

导出的报告会处理已知敏感字段；分享前仍需人工检查自由文本。不要上传 `.env`、认证头、完整 Token、原始账号响应或未经检查的截图。
