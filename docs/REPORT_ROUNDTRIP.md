# v0.1.7：长报告导出与回放

日期：2026-10-17（北京时间）。先复现5项旧版失败，再补充隐私、重复导出、尺寸、CLI文件和本机接口回放检查。

## 保留结构，明确说明省略内容

旧版的全局脱敏预算可能被大块上下文或早期响应耗尽，导致摘要、后续调用或调用列表丢失。新版分别处理报告摘要、调用结构和原始载荷，大响应不会删除后续调用。

单个载荷脱敏后超过80KB时会省略；报告总量控制在1MB导入限制以内。最多展开100条诊断，保留诊断总数和每次调用的总数。超出范围时添加 `REPORT_TRUNCATED` 警告，并记录 `truncation` 元数据；页面展示已展开数／总数，受影响的调用详情也给出说明。

精简发生在脱敏之后，不通过裁切原始文本泄露半截凭证。重复脱敏、下载、Markdown导出不会重复增加同一警告或改变统计。

JSON导出优先使用易读排版；排版后接近1MB时改用紧凑JSON，让本工具导出的文件仍可重新导入。浏览器、CLI文件输出和原生联调快照使用同一序列化函数。

## 回放检查范围

精简报告可以回放，但只能检查保留的证据，无法还原被省略的响应或诊断。再次导入仍保留范围受限警告，不会将它标记为完整检查通过。需要完整排查时，缩小记录范围，重新取得对应调用数据。

较短的常规报告保留完整载荷，不额外产生截断警告。

## 历史与耗时边界

100条历史后追加新的手动检查，保留最近99条上游记录和本次请求，同时明确标注证据窗口缩小。编辑已有调用仍只保留它之前的记录，不使用未来响应。

导入时检查耗时合计是否为有限数字，避免各项都有限但求和溢出，导致报告统计出现空值或Infinity。

完整验证结果见[验收记录](VERIFICATION.md)。本轮未重复浏览器视觉验收。
