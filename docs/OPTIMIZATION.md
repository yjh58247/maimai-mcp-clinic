# v0.1.1 优化记录

日期：2026-10-16（北京时间）。

## 修复

- 对null、标量参数，以及套餐、特调的每层容器和成员进行检查。错误诊断包括具体字段路径，静态分析可返回错误报告，真实发送前返回422并拦截请求。
- 按每一步之前的成功门店查询确定业务编码绑定。自取、得来速和配送切换后，历史正确调用保持通过；真正错误的业务编码仍被拦截。
- 菜单、商品详情、门店券与核价模板统一匹配门店、渠道、业务编码和预约时段。失败响应不能提供上游证据。
- 新时段查询失败时，清除旧时段菜单选择；生成下一步模板时保留预约时间。
- 发送前拦截报告保留相关调用链，避免出现“请求已拦截，但报告没有问题”的情况。
- 浏览器与可安装Skill复用同一份无凭证的纯JavaScript上下文模块。
