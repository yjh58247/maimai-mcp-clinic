01

申请你的 MCP Token

在麦当劳开放平台登录，在控制台激活 MCP。

打开官方开放平台 ↗
02

只在本机配置凭证

在项目目录复制配置示例，并编辑生成的 .env：

Copy-Item .env.example .env
# 在 .env 中填写 MCD_MCP_TOKEN

macOS / Linux：cp .env.example .env

03

重启服务，检查连接

node server.mjs

回到网页，切换“真实接入”，点击“检查连接”。成功后在调用诊断页逐步查询门店、菜单、详情和价格。

网页不接收 Token；报告不保存认证头。
